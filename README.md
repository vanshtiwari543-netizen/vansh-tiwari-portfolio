# Vansh Tiwari Portfolio — GitHub Pages

A responsive multi-page portfolio starter built with HTML, CSS and JavaScript. It is designed to publish directly from GitHub Pages without Vercel.

## Included
- Premium light theme with ivory, charcoal and champagne-gold accents
- Responsive desktop/mobile navigation
- Home page with services, experience, project gallery, filters, approach, FAQ and contact
- Dedicated pages for each service
- Email, WhatsApp and LinkedIn links
- No framework build step required

## Publish directly with GitHub Pages
1. Create a new public repository on GitHub, for example `vansh-tiwari-portfolio`.
2. Upload the contents of this folder (the HTML files, `assets` folder and README) to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes and open the URL GitHub Pages shows on that page.

## Before going live
- Confirm job titles, company names, responsibilities and dates in `index.html`.
- Replace all gallery mockups/placeholders with genuine work samples you have permission to show.
- Review every page and all contact details.
- The current contact form approach is email/WhatsApp links, not a database-backed form.
- GitHub Pages serves static files. Permanent uploads from a visitor-facing admin panel require a separate backend/storage or CMS.
- Interview/coding support is described as preparation and guidance; do not present dishonest completion of assessments as a service.

## Edit content
- Main home page: `index.html`
- Service pages: the individual `.html` files in the root
- Design and responsive styling: `assets/style.css`
- Menu, gallery filtering and FAQ behavior: `assets/script.js`
